# Madux — Site 1 (Lash + catálogo)
`npm install && npm run dev`. Conteúdo editável: `src/data/content.ts` (procure por CONFIRMAR).
Fotos do site: `public/fotos/` (inicio.webp = topo, sobre.webp = final). Fotos dos estilos boneca/esquilo/gatinho:
adicione em `public/fotos/` e declare em `imagens` no content.ts, com as chaves `boneca`, `esquilo`, `gatinho`.
`extras/` guarda os PNGs originais com efeitos. O feedbacks-recortados.png é de outro profissional: só para mockup, não publicar.
Pendências: nome da marca, WhatsApp, preços, fotos dos estilos, feedbacks reais, certificações.
