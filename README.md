# thayline.tech

Repositório de páginas estáticas independentes, pronto para deploy na Vercel.

## Estrutura

- `index.html` na raiz: hub com links para todas as páginas.
- `paginas/`: cada demo em um HTML isolado.
- `vercel.json`: rotas limpas para acessar cada página sem usar a extensão `.html`.

## Rotas principais

- `/` -> hub inicial
- `/calculadora-preco-servico`
- `/cardapio-demo-confeitaria`
- `/cartao-digital-demo`
- `/landing-demo-salao-aurora`
- `/pagina-venda-planilha`

## Deploy na Vercel

1. Conecte este repositório ao projeto na Vercel.
2. Use o deploy estático padrão.
3. Não é necessário comando de build.

Se quiser, também é possível acessar os arquivos diretamente em `/paginas/*.html`.
